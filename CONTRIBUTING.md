# Contributing

- Branch from `main`: `feat/…`, `fix/…`, `chore/…`, `docs/…`.
- Commits: one line, [Conventional Commits](https://www.conventionalcommits.org/) —
  `feat(brain): add provider fallback with single retry`.
- Every change lands through a pull request with green CI.
- Every feature ships with the verification its spec section asks for.
- Never commit secrets, `.env` files or real user data (spec §11.2).
